# discovery-park-map
Discovery Park Interactive Map

An interactive web application that helps UNT students and faculty navigate UNT's Discovery Park campus. Users select their current location and destination, and the app displays the most efficient path between them.

Built for CSCE 3444 (Software Engineering), Section 400 — Group 10.

Project Overview

The app allows students and faculty to:

Adjust the map view — zoom, pan, and switch between floors
Select an origin and destination (by clicking the map or typing a room name) to see the shortest path, shown as a red line
View a photo of a location by clicking on marked points on the map
(Developers only) Edit map data as Discovery Park's layout changes — adding rooms or adjusting intersections

Full functional and non-functional requirements are documented in the team's Software Requirements Specification (SRS).
